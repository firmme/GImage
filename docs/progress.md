## M1 补齐目录变更监听

- 当前打开的目录使用 `notify` 监听。新增、修改、移除或重命名时，浏览页会自动扫描并更新索引。递归监听沿用扫描设置。
- 文件变更在 500 毫秒安静期后合并处理。连续变更最多积累 3 秒便可触发一次扫描，仍需等当前扫描或分页结束，且浏览页没有打开对话框。预览和编辑期间暂存变更，回到浏览页再处理。
- 过滤应用的临时导出文件。正式输出仍会进入图库。过期扫描的缩略图结果不会应用到刷新后的页面。
- Windows 实测使用独立图库和设置目录。初始索引、递归新增、外部修改、重命名、删除子目录均自动更新 SQLite 索引。完整 UI 交互和万图滚动仍待验收。

## 本轮完成

- `ScanOutput` 记录数量截断与读取错误，并提供 `is_complete()`。
- 新增 `Catalog::sync_scan`：不完整扫描只新增或刷新发现的记录，保留未发现项；完整扫描仍标记真实丢失项。已有 `sync_folder` API 保留完整快照语义。
- 应用使用安全同步 API，仅在完整扫描后更新最后扫描时间；扫描状态显示截断或读取错误。
- 最后一次进度回调产生的取消不会丢失。
- 过期扫描跳过索引同步；更新当前会话计数时校验 generation；过期分页事件不清除新页面的加载状态。
- `setup-toolchain.ps1` 配置当前进程 MinGW 路径，开发和打包脚本在构建前自动调用。支持 `GIMAGE_MINGW_BIN`，不修改系统环境变量。
